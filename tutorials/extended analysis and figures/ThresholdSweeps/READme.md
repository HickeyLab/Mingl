# Border Threshold Sweeps and Null Models

This directory contains notebooks used to evaluate how MINGL’s probability threshold affects border identification and enrichment results. It also includes permutation-based null analyses for melanoma borders.

## Files

### `Null_MelanomaBorder.ipynb`

Runs the MINGL border workflow on the melanoma dataset and evaluates whether particular cell types are enriched at tissue-neighborhood borders beyond what would be expected by chance.

The notebook:

- Loads melanoma spatial cell data.
- Calculates neighborhood centroids and per-cell neighborhood probabilities.
- Identifies cells belonging to multiple neighborhoods using a probability threshold.
- Visualizes spatial borders and border composition.
- Compares border cells with cells assigned only to either adjacent neighborhood.
- Calculates cell-type enrichment at selected borders.
- Uses label permutations to generate null enrichment distributions.
- Calculates Jensen–Shannon and cosine similarity between border and neighborhood compositions.
- Compares border assignments across several probability thresholds.

The main detailed comparison uses the border between `Inflamed Tumor` and `Productive T Cell & Tumor`. Verify the exact capitalization of these names in the stored neighborhood-probability labels before running the analysis.

The primary analysis uses a probability threshold of `0.25` and generally performs `1,000` permutations with random seed `42`.

In the permutation analysis, cell-type labels are shuffled while neighborhood probabilities and border assignments remain fixed. This tests whether the observed cell-type composition at a border is different from random allocation of cell-type labels.

### `ThresholdSweeps.ipynb`

Analyzes how changing the probability threshold affects the number, composition, and enrichment of cells classified as borders.

The notebook has two main uses:

1. Analyze previously generated threshold-sweep output files.
2. Refit and evaluate an intestine tissue-unit comparison between `Mucosa` and `Muscularis mucosa`.

The thresholds evaluated are:

```python
[0.01, 0.05, 0.10, 0.15, 0.20, 0.25, 0.33, 0.40, 0.49]
```

The notebook produces:

- Percentage of all cells classified as border cells at each threshold.
- Border cell-type composition across thresholds.
- Cell-type enrichment relative to either adjacent neighborhood.
- Spearman correlations between enrichment results at different thresholds.
- Enrichment-distance measurements using `0.25` as the reference threshold.
- Pairwise distances between all tested thresholds.
- Threshold-sensitivity slopes for individual cell types.
- Enrichment quadrant plots and correlation heatmaps.
- CSV summaries and publication-quality PNG and PDF figures.

## Required input data

### Melanoma analysis

`Null_MelanomaBorder.ipynb` expects a melanoma cell-level table containing:

| Column | Meaning |
|---|---|
| `x`, `y` | Spatial cell coordinates |
| `Cell_Type` | Cell-type annotation |
| `Neighborhood` | Assigned cellular neighborhood |
| `filename` | Tissue region or image identifier |

The notebook saves and reloads a processed AnnData object named:

```text
melanoma_results.h5ad
```

### Threshold-sweep analysis

The first portion of `ThresholdSweeps.ipynb` reads CSV files generated by the broader border-threshold workflow, including:

```text
conditions.csv
threshold_summary.csv
threshold_summary_GENERAL.csv
composition_<condition>.csv
composition_GENERAL_<condition>.csv
enrichment_<condition>.csv
```

`threshold_summary_GENERAL.csv` describes all cells assigned to more than one neighborhood and should be used when calculating overall border prevalence.

`threshold_summary.csv` describes the selected pair of neighborhoods only. These files are not interchangeable.

The refitted intestine analysis expects a cell-level intestine dataset and uses:

- `unique_region` as the region identifier.
- `Mucosa` as the first tissue unit.
- `Muscularis mucosa` as the second tissue unit.

## How to use these notebooks

1. Update the input and output paths at the beginning of each notebook. The current notebooks contain machine-specific Windows paths.
2. Confirm that the column names in your dataset match those expected by the notebook.
3. Run the cells in order.
4. For the melanoma notebook, verify the exact neighborhood names and capitalization before selecting a neighborhood pair.
5. Use `Null_MelanomaBorder.ipynb` to reproduce the melanoma border and permutation analyses.
6. Use `ThresholdSweeps.ipynb` to analyze saved threshold-sweep outputs or rerun the focused intestine tissue-unit threshold analysis.

The refitted intestine section writes a processed object named:

```text
intestine_tissue_unit_threshold_probabilities.h5ad
```

It also exports summary tables such as:

```text
tissue_unit_enrichment_full.csv
tissue_unit_pair_summary_refitted.csv
original_vs_refitted_pair_counts.csv
percent_border_by_threshold.csv
```

## Important notes

- A lower probability threshold generally classifies more cells as belonging to multiple neighborhoods.
- A higher threshold is more restrictive and usually produces fewer border cells.
- The threshold of `0.25` is used as the primary or reference threshold in several analyses.
- Randomized conditions should be excluded when comparing observed threshold sensitivity.
- The null model shuffles cell-type labels; it does not recalculate neighborhood probabilities.
- Several input and output files are stored outside this directory and are not included here.
- All absolute Windows paths must be updated before the notebooks can be run on another computer.
- Notebook outputs may make the files large. Outputs can be cleared before committing to GitHub without removing the code.
